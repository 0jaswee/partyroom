THE PARTY NOTEBOOK

Big fun.
Zero billing setup.

A free Firebase edition for up to 20 people per room.

How it works

Anonymous sign-in gives each browser a player identity. Firebase Realtime Database transactions sync the shared game state. Phones run the game rules, so this edition trusts your friends rather than requiring a paid backend. Reopening an invite in the same browser restores a player while the room is still open.

When the party ends

The host chooses End room and confirms deletion. The room, players, scores, votes, and connection records are deleted. Phones clear the room from memory and remove its code from their URL. The last player explicitly leaving also removes the room. Closing every phone without ending keeps the room available for reconnecting.

What stays on your phone

Your name preference, theme, and anonymous sign-in are separate from game data. No game history or offline game cache is saved by this app. Ending a room does not delete the Firebase authentication account.

Code map

  • app.js: screens and controls.
  • game-engine.js: dice, truth/dare, votes, points and turn transitions.
  • room-model.js: create/join, capacity and password-derived paths.
  • free-firebase.js: direct Firebase transactions and deletion.
  • database.rules.json: access and data validation.
  • README.md and PLAN.md: setup and agent handoff.

Room to grow

Add new games as pure state transitions and corresponding UI screens. Add prompt packs, sounds, and reactions next. A competitive game would need stronger server enforcement; this version is designed for trusted friends and stays on the Spark plan.
